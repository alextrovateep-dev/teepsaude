TeepSaude — Painel Clínico
==========================

COMO EXECUTAR:
  Abra index.html no navegador (Chrome recomendado).

LOGIN DEMO:
  Clínica (admin):  saude@teep.com.br / teepsaude
  Médico:           carlos.mendes / medico1

MÓDULO CONSULTA CLÍNICA:
  Por padrão só o Módulo Monitoramento está ativo.
  Para ativar o Módulo Consulta:
    1. Faça login como clínica
    2. Vá em Configurações → Módulos
    3. Cole uma das chaves abaixo e clique Ativar:
       • TEEP-CONS-2024-DEMO
       • TEEP-CONS-2025-FULL
       • TEEP-CONS-PRO1-ATIV
    4. A sidebar atualiza imediatamente com os novos itens.
  A chave fica salva no localStorage (persiste entre sessões).

ESTRUTURA DE ARQUIVOS:
  index.html              → shell da SPA
  js/dashboard-data.js    → dados mockados
  js/license-module.js    → controle de módulos (NOVO)
  js/dashboard-app.js     → lógica principal (modificado)
  js/exam-module.js       → módulo de exames
  css/dashboard.css       → design system

IA (opcional):
  Vá em Configurações → IA / API Key e cole sua chave Anthropic (sk-ant-...).
  Sem chave o sistema funciona normalmente, apenas sem os recursos de IA.
